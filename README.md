# Для коханої ❤️ — гра «Сортування кольорів»

Веб-гра (PWA), версія 3.1.0. 1000 рівнів, хард-режим, магазин, теми, подарунок дня, петарди з сердечками, анімація переливання, профіль зі статистикою, скринька листів, 15 досягнень і звання. Працює офлайн, відкривається миттєво і ставиться на екран телефону як додаток.

## Публікація на GitHub Pages
1. Завантажте **всі файли** з цієї папки в корінь репозиторію: Add file → Upload files → Commit changes.
2. Settings → Pages → Source: *Deploy from a branch* → гілка `main`, папка `/ (root)` → Save.
3. Через 1–2 хвилини гра відкриється за адресою `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПО/`.
4. На телефоні відкрийте адресу в Safari (iPhone: «Поділитися» → «На екран Домой») або Chrome (Android: ⋮ → «Установить приложение»).

## Файли
- `index.html` — уся гра
- `manifest.webmanifest` — параметри додатку
- `sw.js` — офлайн-режим
- `icon-192.png`, `icon-512.png` — іконки

## Що можна змінити в `index.html`
- `PHOTO` — фото на заставці (data-URI).
- `LETTERS` — листи після кожних 10 рівнів, `SWEET` — милі фрази на кожній перемозі, `FINAL` — лист за 1000-й рівень.
- `SPECIAL.d` — особлива дата у форматі `"ММ-ДД"` (наприклад `"09-21"`). У цей день гра вітає й дарує 100 монет. `SPECIAL.t` — текст вітання.
- Ціни — `ITEMS` (підказки) і `THEMES` (теми оформлення).
- `ACH` — досягнення та нагороди за них, `RANKS` — звання.

## Оновлення
Після зміни файлів на GitHub змініть версію кешу в `sw.js` (`lovesort-3.1.0` → `lovesort-3.1.1`). Гра завжди відкривається з кешу (миттєво), а нова версія завантажується у фоні: відкрийте гру один раз з інтернетом, закрийте й відкрийте знову.

## Збереження
Прогрес (рівень, монети, поточна партія, покупки, тема) зберігається автоматично в браузері на цьому телефоні. Збереження зі старих версій переносяться: куплені теми перетворюються на нові. Якщо очистити дані сайту або перейти на інший телефон, прогрес почнеться заново.
